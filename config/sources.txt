# ============================================================
# FreeNodeMailer 数据源列表
# ------------------------------------------------------------
# 以 # 开头的行为注释。每行一个数据源 URL。
# 支持写法：URL|显示名
#
# 抓取器会为每个 raw.githubusercontent.com 源自动构造「镜像改写链」，
# 因此国内网络下 raw 不通也能取到内容：
#   1) 原地址              raw.githubusercontent.com
#   2) cdn.jsdelivr.net    jsDelivr CDN（国内快，实测首选通道）
#   3) api.github.com      GitHub API（base64）
#   4) fastly / gcore      jsDelivr 备用节点
#
# 抓取失败的源会自动回退到上一次成功抓取的本地缓存。
# 某个源长期 404 的，直接注释掉即可，不影响整体运行。
#
# 想看每个源的真实产出：跑一次 main.py，日志里会逐源打印
# [OK]/[FAIL] + 通道 + 字节数，邮件报告里也有完整表格。
# ============================================================
